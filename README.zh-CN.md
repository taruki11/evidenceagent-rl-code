# EvidenceAgent-RL

> 代码快照发布说明：仅含筛选源码，不含模型、数据、日志或凭据。

EvidenceAgent-RL 是一个围绕论文证据问答的 Agentic-RL 研究工程，研究如何把证据边界、检索策略记忆和工具交互纳入可审计的训练与评测流程。

## 研究工程

- 检索与工具调用环境
- 证据约束的策略/记忆机制
- 训练、冻结选择和评测门禁脚本
- 失败分析与结果审计工具
